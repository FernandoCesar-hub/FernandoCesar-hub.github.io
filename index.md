# postar-youtube

Aplicativo pessoal de Fernando Cesar Moura de Almeida para enviar e agendar videos no proprio canal do YouTube, usando a YouTube Data API v3.

O aplicativo roda apenas no computador do proprio dono e nao e oferecido a outras pessoas.
